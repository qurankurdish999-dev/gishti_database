# سیستەمی داتابەیسی گشتی (دەرمانخانە / کافتریا / مارکێت / دائیرە)

ئەمە بەرنامەیەکی وێب (Flask + SQLite) ـە کە دەتوانرێت بۆ هەر جۆرە بزنسێکی بچووک بەکاربهێنرێت:
دەرمانخانە، کافتریا، مارکێت، خواردنگە، دائیرەی حکومی و هتد.

## ٪١٠٠ ئۆفلاین

ئەم سیستەمە بە تەواوی **ئۆفلاینە** — پێویستی بە هیچ ئینتەرنێتێک نییە، نە بۆ کارپێکردن و نە بۆ
دیزاینی ڕووکار. هەموو فایلەکانی ستایل (CSS) و ئایکۆنەکان (بە شێوەی ئیمۆجی) لۆکاڵین و لەناو
خودی فۆڵدەرەکەدان، هیچ لینکێکی CDN یان فۆنتی گووگڵ بەکارنەهاتووە. دەتوانیت وایفای/داتا لادەیت و
بەرنامەکە کاردەکات.

## کارپێکردن وەک بەرنامەی ڕاستەقینەی دێسکتۆپ (بەبێ وێبگەڕ)

جگە لە شێوازی وێبی ئاسایی (`python app.py` + کردنەوەی لینک لە وێبگەڕدا)، ئێستا دەتوانیت
سیستەمەکە **بکەیتە پەنجەرەیەکی ڕاستەقینەی دێسکتۆپ** — بێ هیچ نیشانەیەکی وێبگەڕ، بێ URL bar،
تەنها وەک هەر بەرنامەیەکی ویندۆزی تر.

### هەنگاوی یەکەم: دامەزراندنی پاکێجی زیادە
```bash
pip install -r requirements.txt
```
(ئەمە `pywebview` و `pyinstaller`یش دەگرێتەخۆ)

### هەنگاوی دووەم: کارپێکردن وەک پەنجەرەی دێسکتۆپ
```bash
python desktop_app.py
```
سێرڤەری Flask لە باکگراوندا کاردەکات و پەنجەرەیەکی جیاواز (native) بۆ سیستەمەکە دەکرێتەوە —
بەبێ هیچ وێبگەڕێک.

## دروستکردنی .exe (بۆ دابەزاندن و دامەزراندن وەک بەرنامەیەکی ئاسایی)

⚠️ پێویستە ئەم هەنگاوانە **لەسەر خودی ویندۆز** ئەنجام بدرێن (نەک لینوکس/مەک)، چونکە
PyInstaller تەنها بۆ هەمان سیستەمی کارپێکردن .exe دروست دەکات.

1. لە تێرمینالی VS Code دا (لەناو فۆڵدەری پڕۆژەکە):
   ```bash
   pip install -r requirements.txt
   ```

2. ئەم فەرمانە بنووسە بۆ دروستکردنی .exe:
   ```bash
   pyinstaller --name "GishtiDatabase" --onefile --windowed ^
     --add-data "templates;templates" ^
     --add-data "static;static" ^
     desktop_app.py
   ```
   (ئەگەر `^` کارنەکرد، هەموو فەرمانەکە لە یەک دێڕدا بنووسە بەبێ `^`.)

3. دوای تەواوبوون، فایلی `GishtiDatabase.exe` لەناو فۆڵدەری `dist` دروست دەبێت.
   ئەم فایلە دەتوانیت بیبەیت بۆ هەر کۆمپیوتەرێکی ویندۆز و کرتەی لەسەر بکەیت — بەبێ پێویستی بە
   دامەزراندنی Python یان VS Code لەسەر ئەو کۆمپیوترە.

4. **گرنگ:** فایلی `database.db` لەتەنیشت خودی `.exe` دروست دەبێت (لە فۆڵدەری `dist`). ئەگەر
   .exe ـەکە بگوازیتەوە بۆ شوێنێکی تر، دڵنیابەرەوە کە فایلی `database.db`یش پێکەوە دەیبەیت،
   ئەگینا سیستەمەکە داتابەیسێکی نوێی بەتاڵ دروست دەکات.

5. بۆ دروستکردنی ئایکۆنی تایبەت بۆ .exe ـەکە، فایلێکی `.ico` دروست بکە و ئەم بەشە زیاد بکە بۆ
   فەرمانی سەرەوە: `--icon=app.ico`

## تایبەتمەندییەکان
- چوونەژوورەوە بە ناوی بەکارهێنەر و وشەی نهێنی
- بەڕێوەبردنی **جۆرەکانی کاڵا** (Categories)
- بەڕێوەبردنی **کاڵاکان** (Products): زیادکردن، دەستکاریکردن، سڕینەوە، گەڕان
- بەشی **فرۆشتن** (Point of Sale / POS): گەڕان بۆ کاڵا، زیادکردنی بۆ سەبەتە، دەرکردنی وەسڵ
- **کەمکردنەوەی ئۆتۆماتیکی کۆگا** لە کاتی فرۆشتن
- **مێژووی وەسڵەکان** و بینین/چاپکردنی هەر وەسڵێک
- **ڕاپۆرتەکان**: فرۆشتنی ڕۆژانە، باشترین کاڵا فرۆشراوەکان، کاڵای کەمبوونەوە
- **بەڕێوەبردنی بەکارهێنەران** (تەنها بۆ admin)
- ڕووکارەکە بە زمانی کوردی و لە لایەنی ڕاست بۆ چەپ (RTL)

## پێداویستییەکان
- Python 3.9 یان بەرزتر
- pip

## هەنگاوەکانی دامەزراندن

1. فایلی zip بکەرەوە (Extract) بۆ فۆڵدەرێک لە کۆمپیوتەرەکەت.

2. لە VS Code دا فۆڵدەرەکە بکەرەوە:
   `File > Open Folder` → فۆڵدەری `gishti_database` هەڵبژێرە.

3. تێرمینالێک بکەرەوە لە VS Code دا (`Ctrl + \``) و ئەم فەرمانانە بنووسە:

   ### دروستکردنی ژینگەی virtual (پێشنیارکراوە):
   ```bash
   python -m venv venv
   ```

   چالاککردنی venv:
   - ویندۆز: `venv\Scripts\activate`
   - مەک/لینوکس: `source venv/bin/activate`

   ### دامەزراندنی پاکێجەکان:
   ```bash
   pip install -r requirements.txt
   ```

4. کارپێکردنی بەرنامەکە:
   ```bash
   python app.py
   ```

5. لە وێبگەڕدا ئەم لینکە بکەرەوە:
   ```
   http://127.0.0.1:5000
   ```

6. چوونەژوورەوە بکە بەم زانیارییانە:
   - ناوی بەکارهێنەر: `admin`
   - وشەی نهێنی: `admin123`

   ⚠️ تکایە دوای یەکەم چوونەژوورەوە، بەکارهێنەرێکی نوێ دروست بکە و ئەم بەکارهێنەرە سرەوە یان وشەی نهێنیت بگۆڕە (لە خشتەی users لەناو database.db).

## چۆنیەتی بەکارهێنان

1. **جۆرەکان** زیاد بکە (بۆ نموونە: دەرمان، خواردنەوە، خۆراکی وشک...) لە بەشی "جۆرەکان".
2. **کاڵاکان** زیاد بکە لە بەشی "کاڵاکان" → "زیادکردنی کاڵا"، نرخ و بڕی کۆگا و بارکۆد دیاری بکە.
3. بۆ فرۆشتن، بچۆ بۆ "فرۆشتنی نوێ"، بە ناو یان بارکۆد بگەڕێ، کاڵا زیادی بکە بۆ سەبەتە، بڕەکەی و داشکاندنی دیاری بکە، پاشان "تەواوکردنی فرۆشتن" بکرێت.
4. وەسڵەکە بەخۆکار دروست دەبێت و دەتوانیت چاپی بکەیت.
5. لە بەشی "ڕاپۆرتەکان" دەتوانیت فرۆشتنی ڕۆژانە و باشترین کاڵاکان و کاڵای کەمبوونەوە ببینیت.

## گۆڕینی ناوی سیستەم بۆ بزنسی تایبەت

- بۆ گۆڕینی ناوی سیستەم (بۆ نموونە "دەرمانخانەی نیشتمان") دەتوانیت لە فایلی
  `templates/base.html` دەقی "داتابەیسی گشتی" بگۆڕیت.
- یەکەکان (دانە، کیلۆ، پاکێت...) لە کاتی زیادکردنی کاڵا بە دەستی دەنووسرێن، بۆیە
  بۆ هەر بزنسێک دەتوانیت یەکەی گونجاو بەکاربهێنیت (بۆ نموونە بۆ دەرمانخانە: پاکێت/قوتوو،
  بۆ کافتریا: دانە/کاسە، بۆ مارکێت: کیلۆ/دانە).

## فایلی داتابەیس

هەموو زانیارییەکان لە فایلی `database.db` (SQLite) هەڵدەگیرێت کە بەخۆکار دروست دەبێت
یەکەم جار کە بەرنامەکە کاری پێدەکرێت. دەتوانیت ئەم فایلە بکۆپی بکەیت بۆ پاشەکەوتکردن (backup).

## گۆڕینی کۆدی نهێنی (secret key)

پێش بەکارهێنانی ڕاستەقینە، لە فایلی `app.py` دا ئەم دێڕە بگۆڕە بۆ نرخێکی نهێنی تایبەت بە خۆت:
```python
app.secret_key = "change-this-secret-key-please"
```

## پشتگیری چەند جۆرە بزنس

بەهۆی ئەوەی داتابەیسەکە بە شێوەیەکی گشتی دروستکراوە (کاڵا، جۆر، فرۆشتن)،
دەتوانرێت بۆ هەر بزنسێکی فرۆشتن/کۆگا بەکاربهێنرێت بەبێ گۆڕانی زۆر لە کۆدەکە:

| بزنس | نموونەی بەکارهێنان |
|---|---|
| دەرمانخانە | کاڵا = دەرمان، جۆر = دەرمانی هەست، بارکۆد بۆ هەر دەرمانێک |
| کافتریا | کاڵا = خواردنەوە/خۆراک، یەکە = دانە/کاسە |
| مارکێت | کاڵا = هەموو کەلوپەلەکان، بارکۆد بۆ سکانکردن |
| دائیرە | کاڵا = پێداویستی نووسینگە، بەبێ بەشی فرۆشتن یان تەنها بۆ کۆنترۆڵی کۆگا |

سوپاس، هیوادارم سیستەمەکە یارمەتیدەر بێت! 🌟
